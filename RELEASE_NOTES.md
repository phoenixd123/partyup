## Downloads

| Platform | File |
|---|---|
| Windows 10/11 (64-bit) | `PartyUp-…-win-x64.exe` — installer |
| macOS (Apple silicon / Intel) | `PartyUp-…-mac-arm64.dmg` / `PartyUp-…-mac-x64.dmg` |
| Linux | `PartyUp-…-linux-x86_64.AppImage` or `PartyUp-…-linux-amd64.deb` |
| Self-hosting | `PartyUp-…-web.zip` (static site) and `PartyUp-…-supabase-sql.zip` (database setup) |

The installers aren't code-signed yet. Windows SmartScreen may say "Windows protected your PC" — choose **More info → Run anyway**. On macOS, right-click the app and choose **Open** the first time.

On first launch the app asks for your Supabase project URL and anon key unless they were built in. See the README for the 5-minute database setup.

## What's new in 1.1

- **Communities:** create public or private servers with text and announcement channels, invite codes (expiry and use limits), owner/admin/member roles, kicks, bans, channel management and an Explore page.
- **Group DMs** with up to 10 friends: rename, add people, remove (owner), leave.
- **Message features everywhere:** replies, reactions, edit (Up arrow edits your last message), delete, pins, search, @mentions with autocomplete and notifications, typing indicators, unread "New" divider, Markdown (`**bold**`, `*italic*`, `` `code` ``, code blocks, `||spoilers||`, links), click a name for a profile card.
- **Custom status**, per-conversation mute, mention notification setting, add friends by username.
- **53 games** (was 12), grouped by genre, with search in onboarding.
- New graphite interface, new icon, and a desktop app for Windows, macOS and Linux.
